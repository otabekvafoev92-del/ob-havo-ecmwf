1Как всё устроено

Osmon состоит из нескольких частей. Каждая живёт в своём месте; все они собираются из одного репозитория на GitHub.

GitHub — репозиторийВесь код: бот, сайт, сборки прогнозов, видео и отчётов. github.com/otabekvafoev92-del/ob-havo-ecmwf
GitHub Actions — «сборщик»Скачивает данные ECMWF, рисует карты, видео и отчёты по расписанию. Позже — на вашем сервере Hetzner.
GitHub Pages — сайтКарты, мини-приложение бота, страница «Погода против прошлого года». Позже — свой домен.
Cloudflare Worker «osmon-bot»Сам Telegram-бот: меню, уведомления, брифинг, ИИ-помощник.
Cloudflare D1 «osmon»База пользователей бота: язык, регион, место, уведомления.
Cloudflare Workers AIУмный помощник: понимает вопрос словами и пишет ответ по нашим данным.
Ветка «sat»Видео со спутника (обновляются каждые ~30 минут).
Ветка «lfl»Динамика к прошлому году: данные, видео, PDF и Excel (3 раза в день).
Источники данныхECMWF (прогнозы), ERA5/Copernicus (архив, норма), EUMETSAT (спутник), Open-Meteo (доступ к данным).

3Сервер Hetzner

Свой сервер работает круглосуточно: данные и программы остаются на диске, видео и отчёты готовы через 15–30 минут после прихода данных, а не через 1–2 часа.

3.1 Аккаунт (один раз)

  1. Регистрация на hetzner.com → Login → Register. В форме данных выберите «Индивидуальный», поле «ИНН» (VAT ID) оставьте пустым, почтовый индекс — ваш (массив Феруза: 100124).
  2. Проверка личности: accounts.hetzner.com → Verification → фото паспорта (или ID-карты) и селфи. Ждать от нескольких минут до суток; придёт письмо.
  3. Включите 2FA: accounts.hetzner.com → 2FA settings (приложение Google Authenticator или аналог).

3.2 Создать сервер

  1. console.hetzner.com → New project → имя Osmon → откройте проект.
  2. Add Server (или Create resource → Servers).
  3. Location: Falkenstein или Nuremberg (Германия); если нет — Helsinki.
  4. Image: Ubuntu 24.04.
  5. Type: Shared vCPU → x86 (Intel/AMD) → Cost-Optimized: CX43 (8 ядер, 16 ГБ, ~€16/мес). Нет в наличии — CX33 (4 ядра, 8 ГБ, ~€8.5). Нет серии CX — CPX32. Arm (CAX) не берите.
  6. Networking: оставьте Public IPv4 и IPv6 (IPv4 обязателен — GitHub работает только через него).
  7. SSH keys — можно пропустить (пароль root придёт на почту). Volumes, Firewalls, Backups — не трогать.
  8. Cloud config (поле «User data») — вставьте целиком текст ниже. Он сам поставит всё, что нужно сборкам.
  9. Name: osmon-1 → Create & Buy now. Через 1–2 минуты статус станет Running; подождите ещё ~5 минут, пока выполнится Cloud config.
#cloud-config
package_update: true
packages: [ffmpeg, fonts-inter, python3-pip, python3-venv, git, curl, jq, libeccodes0, libeccodes-tools, unzip]
runcmd:
  - useradd -m -s /bin/bash runner
  - mkdir -p /home/runner/actions-runner /data && chown runner:runner /data
  - cd /home/runner/actions-runner && curl -sSL -o r.tgz https://github.com/actions/runner/releases/download/v2.321.0/actions-runner-linux-x64-2.321.0.tar.gz && tar xzf r.tgz && rm r.tgz
  - chown -R runner:runner /home/runner/actions-runner
  - /home/runner/actions-runner/bin/installdependencies.sh
Если CX43 / CX33 «Sold out»Дешёвые серии CX/CAX у Hetzner после повышения цен в июне 2026 часто распроданы. Попробуйте другую локацию (Nuremberg ↔ Falkenstein ↔ Helsinki) или возьмите CPX32. Сервер всегда можно заменить позже.

4Подключить сервер к GitHub

После этого все сборки (прогнозы, видео, отчёты) будут выполняться на вашем сервере. Паролей сервера никому давать не нужно: сервер сам забирает задания у GitHub.

  1. GitHub → репозиторий ob-havo-ecmwf → Settings → слева Actions → Runners → New self-hosted runner.
  2. Выберите Linux и x64. В блоке Configure скопируйте строку, которая начинается с ./config.sh --url https://github.com/... — в ней ваш временный ключ (действует ~1 час, никому не пересылайте).
  3. Hetzner → проект Osmon → сервер osmon-1 → значок >_ (Console) справа вверху. Войдите: логин root, пароль — из письма Hetzner (при первом входе попросит сменить).
  4. В консоли выполните по очереди (после ./config.sh вставьте скопированное из GitHub продолжение строки и добавьте в конец --labels osmon --unattended): 
    su - runner
cd actions-runner
./config.sh --url https://github.com/otabekvafoev92-del/ob-havo-ecmwf --token ВАШ_КЛЮЧ_ИЗ_GITHUB --labels osmon --unattended
exit
cd /home/runner/actions-runner && ./svc.sh install runner && ./svc.sh start
  5. Вернитесь в GitHub → Settings → Actions → Runners: сервер osmon-1 должен быть со статусом Idle (зелёный). Готово — напишите в чат, и сборки переключатся на сервер.
Подсказка по консоли HetznerВставка текста: правая кнопка мыши → Paste, либо кнопка «Paste» в панели консоли. Если вставка не работает — наберите команду вручную; ключ из GitHub проще вставить в строку целиком, скопировав её из GitHub полностью.
Если сервер нужно заменить или перезапуститьПерезапуск: Hetzner → сервер → Power → Reboot — раннер запустится сам. Новый сервер: повторите разделы 3.2 и 4 (в GitHub удалите старый раннер: Runners → … → Remove).

5Домен для сайта

  1. dash.cloudflare.com → Domains → Register (Registrar). В поиске введите osmon.ai (свободен, $80 в год) и/или osmonweather.com ($11.17 в год).
  2. Purchase → заполните контакты → оплата картой. Включите Auto-renew, чтобы домен не пропал.
  3. Подключение домена к сайту и почту/редиректы настроит Claude: напишите в чат, какой домен куплен.

Цены Cloudflare Registrar — по себестоимости, без наценки. Домен в зоне .uz покупается у узбекских регистраторов отдельно (по желанию).

6Автозаливка бота (токен Cloudflare)

После этого каждое изменение бота в GitHub само попадает в Telegram — без входа в Cloudflare.

6.1 Создать токен в Cloudflare

  1. Откройте dash.cloudflare.com/profile/api-tokens → Create Token.
  2. Шаблон Edit Cloudflare Workers → Use template.
  3. В блоке Account policy нажмите ✏️ → добавьте разрешение Workers AI → Edit (для умного помощника). Не нашли — пропустите.
  4. Token expiration: No expiration (иначе через 7 дней перестанет работать).
  5. Continue to summary → Create Token → Copy. Токен показывается один раз.

6.2 Сохранить токен в GitHub

  1. Откройте github.com/otabekvafoev92-del/ob-havo-ecmwf/settings/secrets/actions → New repository secret.
  2. Name: CLOUDFLARE_API_TOKEN, Secret: вставьте токен → Add secret.
  3. Проверка: Actions → Deploy bot → Run workflow. Зелёная галочка — бот залит.
Никогда не пересылайте токенНи в чат, ни в Telegram, ни по почте. В GitHub он хранится скрыто; если токен утёк — удалите его в Cloudflare (API Tokens → Roll / Delete) и создайте новый.

7Залить бота вручную и откатить

7.1 Залить вручную (если автозаливка не настроена или сломалась)

  1. Откройте файл бота: github.com/otabekvafoev92-del/ob-havo-ecmwf/blob/main/telegram/worker.js → кнопка Raw → выделите всё (Ctrl+A) → скопируйте (Ctrl+C).
  2. dash.cloudflare.com → Workers & Pages → osmon-bot → Edit code.
  3. В редакторе слева откройте worker.js, выделите весь код (Ctrl+A), вставьте новый (Ctrl+V) → Deploy.
  4. Проверьте бота: напишите ему /start — должно прийти меню.

7.2 Откатить на прошлую версию (если после обновления бот сломался)

  1. osmon-bot → вкладка Deployments.
  2. У предыдущей версии нажмите … → Rollback → подтвердите. Бот вернётся к прежнему коду за несколько секунд.
Настройки бота не трогатьosmon-bot → Settings: секреты BOT_TOKEN, GH_TOKEN, переменная SITE_URL, привязки DB (D1) и AI. Если их удалить, бот перестанет работать.

10Безопасность

  • Включите 2FA в Hetzner, Cloudflare и GitHub.
  • Токены и ключи храните только в «секретах» (GitHub Secrets, Cloudflare Secrets). Не пересылайте их в чаты.
  • Если кто-то получил доступ к токену: удалите его в сервисе, где создавали, и создайте новый.
  • Пароль root сервера смените при первом входе и храните в менеджере паролей.
